# django-blogpost

# About

A beginner‑friendly, accessible website designed to share knowledge through blog posts, organized into clear categories for easy navigation. The platform helps readers explore educational content in a structured way, with interactive features such as likes to encourage engagement. Each post provides concise insights, while categories allow users to filter topics that matter most to them. The site also includes resources and links for further learning, making it a supportive hub for anyone seeking to expand their understanding. Built with Django, the project emphasizes simplicity, usability, and community interaction, ensuring that both newcomers and experienced learners can benefit from the content provided

# Purpose

The purpose is to create a knowledge-sharing platform where:

- Writers/Admins can publish educational content.
- Readers can explore posts by category and engage with them through likes.
- Community interaction is encouraged by tracking likes and (optionally) adding comments.

# User Value

- Easy-to-navigate one-page layout
- Responsive design for mobile and desktop
- WCAG-compliant accessibility features
- create blog add comment and likes
